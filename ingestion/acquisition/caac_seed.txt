# CAAC (Civil Aviation Administration of China) PDF seed manifest — Simplified Chinese.
#
# The CAAC on-site index is JS/JSONP (unscrapable), so we bypass it: these direct
# PDF URLs were harvested ONCE via search engine (site:caac.gov.cn filetype:pdf,
# markers 咨询通告 / 信息通告 / 运行安全通告) on 2026-06-02 and committed for
# reproducibility. caac.py reads this file, filters to caac.gov.cn *.pdf, dedupes
# by basename (the opaque P-number is unique per doc), and download()s each into
# data/corpus/zh/caac/.
#
# One URL per line. Blank lines and #-comments are ignored. URLs are kept verbatim
# as the search engine returned them (including /PHONE/ and /English/ mirrors) —
# those resolve; we do not rewrite paths we haven't verified.
#
# Whether a given PDF is scanned (image-only → fires Chinese OCR) vs born-digital
# is decided at ingest by pdf.extract_page's image_only flag, not asserted here.
# Older ACs (2003–2005) are the likely-scanned ones; newer (2018+) are born-digital.
